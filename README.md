Arcade Hub is a premium, open-source collection of classic casual web games rebuilt from the ground up using modern web technologies. It features a stunning glassmorphism UI, fluid animations, and a fully responsive design that works flawlessly across all devices.

## ✨ Features

- **7 Classic Mini-Games**: Enjoy fully functional remakes of classic games with modern state management.
- **Premium Design**: Beautiful, glassmorphism-inspired UI with vibrant gradients and smooth `@keyframes` animations.
- **Dark / Light Mode**: Full theme support utilizing Tailwind's dark mode capabilities.
- **Lightning Fast**: Built on the Next.js 15 App Router for instant page loads and optimal performance.
- **Fully Responsive**: Play on desktop, tablet, or mobile devices seamlessly.

## 🎮 Included Games

1. **Tic Tac Toe**: The classic X's and O's game. Play against a friend locally!
2. **Memory Game**: Test your memory by matching pairs of cards in the fewest moves possible.
3. **Snake Game**: Slither around, eat apples, and grow your snake without hitting the walls.
4. **Rock Paper Scissors**: The ultimate showdown of hands against a computer opponent.
5. **Whack-a-Mole**: A fast-paced reflex challenge! Whack the moles as they pop up.
6. **Connect Four**: Drop your pieces and be the first to connect 4 in a row.
7. **2048**: Slide and merge tiles to reach the elusive 2048 tile!

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v18.17 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/arcade-hub.git
   ```
2. Navigate to the project directory:
   ```bash
   cd arcade-hub
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
